# موقع الزُمردة بيوتي سنتر — النسخة النهائية للمرحلة الثالثة

موقع عام بهوية الزُمردة الأصلية، ولوحة تحكم عربية متصلة بقاعدة بيانات على الخادم.
كل تعديل تحفظه المديرة في اللوحة يظهر في الموقع العام فوراً.

| الوثيقة | المحتوى |
|---|---|
| [docs/WINDOWS.md](docs/WINDOWS.md) | التشغيل على Windows 11 وVS Code خطوة بخطوة |
| [docs/DEPLOY.md](docs/DEPLOY.md) | النشر الفعلي على الإنترنت (خادم VPS أو استضافة cPanel) |
| [docs/TEST_REPORT.md](docs/TEST_REPORT.md) | تقرير الاختبارات |
| [docs/STATUS.md](docs/STATUS.md) | حالة العمل وما تغيّر في كل خطوة، والمطلوب من صاحبة المشروع |

## التشغيل السريع

```
python -m venv .venv
.venv\Scripts\activate          (على Linux/macOS:  source .venv/bin/activate)
pip install -r requirements.txt
python manage.py init-db
python manage.py create-admin    ← يُنشئ حساب المديرة (اسم مستخدم + كلمة مرور مخفية)
set ZUM_COOKIE_SECURE=0          (للتجربة المحلية على http فقط؛ على Linux: export ZUM_COOKIE_SECURE=0)
python serve.py
```
ثم افتحي: الموقع `http://127.0.0.1:8000/` — لوحة التحكم `http://127.0.0.1:8000/admin/`

على Windows يكفي تشغيل `windows\setup.bat` ثم `windows\create-admin.bat` ثم `windows\run-local.bat`.

## بنية المشروع

| المسار | الوصف |
|---|---|
| `index.html` | الموقع العام الأصلي. **لم يتغير بايتاً واحداً**؛ يُستخدم قالباً يملؤه الخادم ببيانات القاعدة |
| `images/` | الشعار وصور الموقع الأصلية + فيديو الواجهة `promo-bg.mp4` |
| `admin/` | لوحة التحكم (التصميم نفسه من المرحلة الثانية، والحفظ صار على الخادم) |
| `server/` | خادم Flask: القاعدة، تسجيل الدخول، واجهات القراءة والكتابة، توليد الصفحة العامة، رفع الصور |
| `uploads/` | الصور التي ترفعها المديرة من اللوحة (تُنشأ تلقائياً) |
| `data/` | قاعدة البيانات `zumurrud.db` والنسخ الاحتياطية `data/backups/` (تُنشأ تلقائياً) |
| `manage.py` | أوامر الإدارة (الحساب، النسخ الاحتياطي، الاسترجاع، فحص الجاهزية) |
| `serve.py` | تشغيل الإنتاج بخادم waitress (Windows وLinux) |
| `run.py` | تشغيل التطوير بخادم Flask |
| `wsgi.py` / `passenger_wsgi.py` | نقاط دخول لـ gunicorn واستضافات cPanel |
| `windows/` | ملفات تشغيل جاهزة لـ Windows |
| `deploy/` | إعدادات nginx وsystemd والنسخ الاحتياطي اليومي |
| `tests/` | 132 اختباراً آلياً + اختبارات متصفح حقيقي في `tests/e2e/` |
| `docs/reference/` | ملف تصميم بطاقة الإهداء المطبوعة (للمرجع فقط، غير مستخدم في الموقع) |
| `backup-phase1/` | النسخة الاحتياطية من المرحلة الأولى |

## أوامر الإدارة

```
python manage.py create-admin       إنشاء حساب المديرة (مرة واحدة)
python manage.py change-password    تغيير كلمة المرور (يُنهي كل الجلسات)
python manage.py admin-info         عرض اسم المستخدم
python manage.py status             أعداد البيانات
python manage.py check              فحص الجاهزية قبل النشر
python manage.py backup             نسخة احتياطية فورية
python manage.py list-backups       عرض النسخ
python manage.py restore <ملف>      استرجاع نسخة (أوقفي الخادم أولاً)
python manage.py cleanup-uploads    حذف الصور المرفوعة غير المستخدمة (--dry-run للمعاينة)
python manage.py reseed             إعادة بناء القاعدة من البيانات الأصلية (بعد نسخة احتياطية)
```

## الأمان باختصار

- لا يوجد أي حساب أو كلمة مرور جاهزة داخل الكود. الحساب يُنشأ بالأمر `create-admin`، وكلمة المرور تُخزَّن مجزّأة (scrypt).
- كل مسارات `/admin` و`/api/admin` تتطلب تسجيل الدخول، وكل عملية كتابة تتطلب رمز CSRF ومصدراً من الموقع نفسه.
- تقييد محاولات الدخول الخاطئة، وانتهاء الجلسة بعد 30 دقيقة خمول أو 8 ساعات.
- كل البيانات يُتحقق منها على الخادم (الأسعار، الروابط، الأطوال، مسارات الصور)، وكل النصوص تُهرَّب عند العرض.
- الصور المرفوعة يُتحقق من محتواها الفعلي، وتُعاد كتابتها (تصغير وحذف بيانات EXIF والموقع الجغرافي)، وتُحفظ بأسماء عشوائية.
- نسخة احتياطية تلقائية من القاعدة قبل كل استيراد أو استعادة، ودورياً كل 6 ساعات عند الحفظ.
