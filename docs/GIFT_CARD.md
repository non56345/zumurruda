# بطاقة الإهداء: طلبات الزبائن وتجهيز البطاقة

**الزبونة (الموقع العام، قسم «إهداء»):** ترى صورة البطاقة الأصلية كما هي (`images/zumurruda_gift_card_page_1.png`) وتعبّئ: إلى، من، الهدية، رسالة (اختياري)، رقم هاتفها. لا تكتب فوق البطاقة. يُحفظ الطلب في الجدول `gift_orders`.

**المديرة (لوحة التحكم ← «طلبات الإهداء»):** تفتح الطلب فتظهر كل بيانات الزبونة، ثم تجهّز البطاقة:
- اسحبي أي نص لتحريكه، أو استخدمي الأسهم (Shift للحركة الأكبر)، أو الحقول الجانبية: الموضع، الحجم، العرض، ارتفاع السطر، المحاذاة، الخط، السُّمك، اللون.
- العنصر «القيمة» اختياري (فارغ افتراضياً) لكتابة قيمة البطاقة إن رغبتِ.
- «معاينة البطاقة» تعرض الشكل النهائي، و«حفظ التجهيز» يحفظ النصوص والمواضع للطلب.
- «تحميل البطاقة PNG» بجودة 2× (2484×1294) أو 3× (3726×1941).
- «حفظ المواضع كإعداد افتراضي» يجعل المواضع الحالية بداية كل بطاقة جديدة.
- صورة البطاقة الأصلية لا تُعدَّل أبداً؛ يُحفظ فقط النص والإحداثيات (JSON في عمود `card`).

**قاعدة البيانات:** جدول جديد `gift_orders` يُنشأ تلقائياً عند الإقلاع (`CREATE TABLE IF NOT EXISTS`) دون المساس بأي بيانات. المواضع الافتراضية المخصّصة تُحفظ في `meta` بالمفتاح `gift_card_layout`.

**الأمان:** المسار العام الوحيد هو `POST /api/gift-orders` (فحص مصدر الطلب، حد 5 طلبات/ساعة لكل عنوان IP، حقل فخ للروبوتات، تحقق كامل على الخادم). كل مسارات `/api/admin/gift-*` تتطلب تسجيل الدخول ورمز CSRF.

**الخطوط:** الكتابة على البطاقة تستخدم خطوط جوجل التي تحمّلها اللوحة أصلاً (IBM Plex Sans Arabic وEl Messiri)، فتحتاج اللوحة اتصالاً بالإنترنت ليظهر الخط الصحيح في الصورة المحمّلة؛ دونه يُستخدم خط النظام.

**اختبار المتصفح:** `python tests/e2e/e2e_gift.py http://127.0.0.1:8765` (انظري رأس الملف).
