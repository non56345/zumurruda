# التشغيل على Windows 11 وVS Code (أرشيفي - Legacy)

> **تنبيه (Legacy):** هذا الدليل أرشيفي وكان مخصصاً للنسخة القديمة المعتمدة على SQLite والملفات المحلية. الموقع رُحّل بالكامل ليعمل على **MongoDB Atlas** والنشر السحابي على **Vercel Serverless**. راجعي دليل النشر الحالي في [docs/DEPLOY.md](DEPLOY.md) ودليل التطوير في [README.md](../README.md).

---

1. **Python 3.11 أو أحدث** من https://www.python.org/downloads/
   أثناء التثبيت فعّلي خيار **Add python.exe to PATH**.
2. **VS Code** من https://code.visualstudio.com/
3. فكّي ضغط ملف المشروع في مجلد مسار اسمه بالإنجليزية، مثلاً `C:\Sites\zumurrud`.

## 2) التجهيز (مرة واحدة)

افتحي المجلد `zumurrud`، ثم انقري مرتين على:

1. `windows\setup.bat` ينشئ بيئة Python خاصة (`.venv`)، ويثبّت المكتبات، وينشئ قاعدة البيانات من بيانات الموقع الأصلية.
2. `windows\create-admin.bat` يطلب:
   - اسم المستخدم: أحرف إنجليزية صغيرة وأرقام، مثل `manager`.
   - كلمة المرور: 12 حرفاً على الأقل، ولا تظهر أثناء الكتابة، وهذا طبيعي.

## 3) التشغيل اليومي للتجربة

انقري مرتين على `windows\run-local.bat` فيفتح المتصفح تلقائياً على:

- الموقع: http://127.0.0.1:8000/
- لوحة التحكم: http://127.0.0.1:8000/admin/

لإيقاف الخادم: أغلقي النافذة السوداء أو اضغطي `Ctrl + C` فيها.

> `run-local.bat` يشغّل الموقع بإعداد مخصص للتجربة على الجهاز فقط (`ZUM_COOKIE_SECURE=0`). لا يُستخدم هذا الإعداد على الإنترنت.

## 4) العمل من VS Code

1. **File → Open Folder** واختاري مجلد `zumurrud`.
2. ثبّتي الإضافات المقترحة عندما يظهر الإشعار (Python وPython Debugger).
3. إن سأل VS Code عن المفسّر: اختاري `.venv\Scripts\python.exe` (بعد تشغيل `setup.bat` مرة).
4. للتشغيل: من الشريط الجانبي **Run and Debug**، اختاري «الزُمردة: تشغيل محلي» واضغطي ▶.
5. للاختبارات: **Terminal → Run Task** ثم «الزُمردة: الاختبارات»، أو من أيقونة **Testing** في الشريط الجانبي.
6. مهام أخرى من **Run Task**: «فحص الجاهزية للنشر» و«نسخة احتياطية».

من طرفية VS Code مباشرة:
```
.venv\Scripts\activate
python manage.py status
python -m unittest discover -s tests -v
```

## 5) النسخ الاحتياطي على الجهاز

- انقري `windows\backup.bat`، فتُحفظ نسخة في `data\backups\`.
- يأخذ الخادم نسخاً تلقائياً أيضاً قبل الاستيراد وقبل الاستعادة، وكل 6 ساعات عند الحفظ.
- للاسترجاع: أوقفي الخادم، ثم نفّذي:
  `python manage.py restore <اسم الملف>`

## مشاكل شائعة

| المشكلة | الحل |
|---|---|
| `Python is not installed` | ثبّتي Python مع خيار Add to PATH، ثم أعيدي تشغيل `setup.bat` |
| `Run windows\setup.bat first` | لم تُنشأ البيئة بعد؛ شغّلي `setup.bat` |
| المنفذ 8000 مستخدم | أضيفي في ملف `.env` السطر `ZUM_PORT=8080` ثم افتحي http://127.0.0.1:8080/ |
| تسجيل الدخول يعيدني لصفحة الدخول | تأكدي أنكِ شغّلتِ عبر `run-local.bat` أو إعداد VS Code (يضبطان التجربة المحلية) |
| «محاولات كثيرة خاطئة» | انتظري 15 دقيقة، أو غيّري كلمة المرور بـ `python manage.py change-password` |
| نسيتُ كلمة المرور | `python manage.py change-password` من مجلد المشروع |
| الخطوط تظهر مختلفة | الخطوط تُحمَّل من Google Fonts وتحتاج إنترنت؛ بدونها تُستخدم خطوط النظام مؤقتاً |
