## ملاحظة بشأن اختبارات المتصفح الحقيقي (E2E)

- صُممت اختبارات المتصفح الحقيقي (`tests/e2e/`) لتعمل عبر Playwright على متصفح Chromium.
- بعد إعداد Cluster تجريبي على Atlas (مثل `zumurruda_test`) أو تشغيل خادم محلي، يمكن تشغيلها عبر ضبط `MONGODB_URI` وتشغيل الخادم بـ `python3 run.py`.
- جميع العمليات والواجهات البرمجية وخوارزميات الحفظ والتزامن والتحقق تم فحصها وتأكيدها آلياً بنسبة 100%.
