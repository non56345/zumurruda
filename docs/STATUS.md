# حالة المشروع وسجل التسليم (مرحلة الترحيل السحابي)

**آخر تحديث:** اكتمال الترحيل من SQLite إلى MongoDB Atlas والنشر على Vercel Serverless بالكامل.
**الفرع الحالي:** `feat/mongodb-vercel`
**حالة الاختبارات:** 157 اختباراً آلياً بنسبة نجاح 100%.

---

## 1. ما تم إنجازه في مرحلة الترحيل السحابي

| المكون | التعديل | التفاصيل التقنية |
|---|---|---|
| **قاعدة البيانات** | SQLite ← MongoDB Atlas | وثيقة `site` واحدة تجمع بيانات الموقع مع رقم مراجعة `rev` وتحكم تزامني متفائل (Compare-and-Set). |
| **النشر السحابي** | Waitress/VPS ← Vercel Serverless | دالة Python Serverless عبر `app.py` وتكوين `vercel.json` لمنطقة `fra1` القريبة من فرانكفورت. |
| **التهيئة التلقائية** | إلغاء `init-db` كشرط للتشغيل | التجهيز التلقائي للبيانات الأولية والفهارس مع أول طلب للويب (`ensure_ready`). |
| **حساب المديرة** | إلغاء `create-admin` اليدوي | صفحة `/admin/setup` في المتصفح محمية برمز `SETUP_TOKEN` وتقييد محاولات وقفل ذرّي. |
| **الصور المرفوعة** | ملفات محلية ← MongoDB (`uploads`) | تصغير ومعالجة بـ Pillow وتخزين في MongoDB مع تخديم بكاش سنة وETag وعزل أمني وحد 4MB. |
| **بطاقات الإهداء** | SQLite ← MongoDB (`gift_orders`) | ترقيم متسلسل عبر collection `counters`، وتحديد معدل الإرسال بالـ IP. |
| **النسخ الاحتياطي** | نسخ ملفات محلي ← Atlas Backups | نسخ سحابي مستمر، مع لقطات احتياطية في `site_backups` قبل عمليات الاستيراد. |
| **الاختبارات** | محاكاة كاملة بـ mongomock | نجاح 157 اختباراً (بما فيها اختبارات الترحيل والتزامن والأمان الجديدة). |

---

## 2. ما لم يتغير إطلاقاً (مطابقة كاملة)

1. **`index.html`:** لم يتغير بايت واحد منه؛ يظل متطابقاً تماماً مع الأصل قبل تعديلات المديرة.
2. **الواجهة ولوحة التحكم:** نفس التصميم ونفس الخطوط ونفس النصوص والرسائل العربية.
3. **أمان الجلسات:** تجزئة scrypt لكلمات المرور، SHA-256 لتوكن الجلسة، حماية CSRF، ترويسات الأمان (HSTS, nosniff, SAMEORIGIN).

---

## 3. ما يجب على صاحبة المشروع فعله (مرة واحدة) للنشر على Vercel

1. **MongoDB Atlas:**
   - إنشاء Cluster مجاني (M0) في منطقة **AWS eu-central-1 (Frankfurt)**.
   - إنشاء مستخدم بصلاحية `readWrite` على قاعدة `zumurruda`.
   - إضافة `0.0.0.0/0` في Network Access.
   - نسخ Connection String (`mongodb+srv://...`).
2. **Vercel:**
   - استيراد مستودع المشروع وإضافة متغيرات البيئة في Project Settings لبيئتي **Production** و **Preview**:
     - `MONGODB_URI`
     - `MONGODB_DB=zumurruda`
     - `SECRET_KEY` (64+ حرف عشوائي)
     - `SETUP_TOKEN` (24+ حرف عشوائي)
     - `ZUM_COOKIE_SECURE=1`
     - `ZUM_PROXY_HOPS=1`
     - `ZUM_AUTO_INIT=1`
   - النشر التلقائي عبر Vercel.
3. **المتصفح:**
   - فتح `https://your-domain.vercel.app/admin/setup` وإدخال `SETUP_TOKEN` لإنشاء حساب المديرة.
